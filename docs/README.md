# HomeShell docs

One line per doc, grouped by who reads it. Each fact has one home; the docs link to each other
rather than repeat.

## Users

- [README](../README.md): what HomeShell is, install, run and first use.
- [CONFIGURATION.md](CONFIGURATION.md): the data directory, settings, CLI flags and environment
  variables.

## Developers

- [CONTEXT.md](../CONTEXT.md): the glossary of domain terms. Start here for the vocabulary.
- [ARCHITECTURE.md](ARCHITECTURE.md): components, processes, the state model, persistence, agent
  detection, the session bridge and the desktop shell.
- [API.md](API.md): the daemon's HTTP endpoints, authentication and SSE event streams.
- [PROVIDERS.md](PROVIDERS.md): the provider contracts, the existing providers and how to add
  one.
- [DEV.md](DEV.md): toolchain, build, run, test, lint, CI and releases.
- [AGENTS.md](../AGENTS.md): rules for agents and contributors, including which doc a change
  updates.
- [CHANGELOG.md](../CHANGELOG.md): user-visible changes.

## Project

- [CONTRIBUTING.md](../CONTRIBUTING.md): contribution terms, workflow and project contact.
- [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md): community conduct and reporting.
- [SECURITY.md](../SECURITY.md): private vulnerability reporting and supported versions.
- [LICENSE](../LICENSE): the project license.
- [NOTICE.md](../NOTICE.md): project and third-party notices.
