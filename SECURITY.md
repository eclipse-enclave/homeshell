# Security Policy

HomeShell follows the
[Eclipse Foundation Vulnerability Reporting Policy](https://www.eclipse.org/security/policy/).

## Reporting a Vulnerability

Please do not disclose vulnerabilities through public issues, discussions or pull requests.
Report them privately through the Eclipse Foundation Vulnerability Reporting Tracker:

https://gitlab.eclipse.org/security/vulnerability-reports/-/work_items/new?issue[confidential]=true

Include the following information where available:

- Affected version or commit, operating system and relevant configuration.
- The type of issue, its impact and how an attacker could exploit it.
- Steps to reproduce, affected source locations and a proof of concept.
- Relevant logs, with credentials and other secrets removed.

See the [Eclipse Foundation Security page](https://www.eclipse.org/security/) for more
information about reporting and coordinated disclosure.

## Supported Versions

Eclipse Home does not currently maintain stable release lines. Security fixes are applied to the
current main branch and published in the latest rolling prerelease. Older rolling builds are not
supported.
