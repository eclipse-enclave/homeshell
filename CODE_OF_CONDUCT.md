# Community Code of Conduct

HomeShell adopts the
[Eclipse Foundation Community Code of Conduct](https://www.eclipse.org/org/documents/community-code-of-conduct/).
It applies to participation in this project's community spaces and activities.

Please read the full policy for expected behavior, scope, reporting and enforcement procedures.

## Reporting

Report conduct concerns privately to the Eclipse Foundation Conduct Committee at
[conduct@eclipse-foundation.org](mailto:conduct@eclipse-foundation.org).

For software vulnerabilities, use [SECURITY.md](SECURITY.md) instead.
